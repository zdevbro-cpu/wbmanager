# 원방 스크랩 관리 — 담당자 업무 지원 시스템 구축 기획

> 근거 자료: `data/01. 원방자료` (입출고 관리 · 총무), 입고/출고/폐기물/재고이동 샘플 엑셀, ecount 입력 화면, 대표이사 손익보고
> 목적: 담당자의 **수기·반복 작업을 줄이고 오류를 없애는** 방향으로 시스템이 지원할 내용을 정리

---

## 1. 담당자 업무 현황 (폴더 분석 요약)

담당자는 크게 **입출고 관리**와 **총무** 두 축의 업무를 ecount + 다수의 Excel 파일로 병행 처리하고 있다.

**입출고 관리**
- 계근(계량증명서) → Excel 입고/출고현황 → ecount 구매·판매입력으로 **같은 데이터를 3중 수기 입력**
- 거래처별·현장별로 시트가 수십 개(세화철강, 대신에스티에스, 다옴금속, 다문산업, 선진알앤디, 포스코_KM안산 등)로 쪼개져 개별 관리
- **갑지(피벗 집계)** 를 수동으로 새로고침하여 월별·현장별·거래처별 소계 산출
- 폐기물은 **올바로 신고 기준업체량** 을 별도 기준으로 입고량 관리 (투플러스·주원·도솔환경 등)
- 재고이동을 대상별(투플러스, 크로스창고, SR5 현장, 어린이집)로 각각 시트 관리
- 매일 출고현황을 **카톡방에 이미지 형태로 일일보고**, 계량증명서·입출고현황 별도 전달
- 회계: 판매일괄회계반영(매출전표) → 국세청 계산서 발행 → 출고현황에 단가수정·발행·입금 표시 수기 정정

**총무**
- 법인차량·중장비·어테치: 이동계획(카톡) → 이동내역 작성 → 정비명세서 → **차량검사 유효기간** 관리
- 임직원·자격증: 현황·자격증·교육·대시보드, **자격증 만료** 관리
- 도시락 주문 현황 관리

## 2. 실제 데이터에서 확인된 문제점 (Pain Points)

| # | 문제 | 근거(실제 자료) | 영향 |
|---|------|----------------|------|
| P1 | 동일 계근값 3중 입력 (증명서→Excel→ecount) | 입고현황·출고현황 시트 컬럼이 ecount 입력 필드와 중복 | 시간 소모·전사 오류 |
| P2 | 수식 깨짐 방치 | 갑지 시트에 `#REF!` 다수 존재 | 집계 신뢰도 저하 |
| P3 | 정산중량=재고반영중량 수기 일치 | 판매입력 화면 "정산중량과 동일하게 작성 필수" 경고 | 재고·매출 불일치 위험 |
| P4 | 입고/출고 컬럼 순서 상이 | 입고=총중량·공차·감량·입고량 / 출고=공차·총·실·정산중량 | 통합·자동화 저해 |
| P5 | 거래처별 시트 수동 분리 | 갑지 외 거래처별 개별 시트 다수 | 유지보수 부담 |
| P6 | 갑지 피벗 수동 새로고침 | 9-3, 9-5 "기준일 변경·새로고침" 단계 | 최신성 미보장 |
| P7 | 폐기물 올바로 기준량 이중관리 | 폐기물 시트 `올바로(O/X)` 컬럼, 기준업체량 별도 | 신고·정산 불일치 |
| P8 | 일일보고 수작업(이미지) | 출고현황 공유파일→카톡 이미지 | 반복 노동 |
| P9 | 재고평가(미실현손익) 수기 | 대표이사 손익보고 기반 | 손익 확정 지연 |
| P10 | 총무 만료 알림 부재 | 차량검사 유효기간·자격증 현황 시트만 존재 | 누락 리스크 |

## 3. 시스템이 지원해야 할 핵심 기능 (담당자 관점)

### 3.1 계근 1회 입력 → 전 채널 자동 반영  *(P1·P3·P4 해결)*
- 계량증명서를 **1회 등록**(사진/PDF 업로드 또는 폼 입력)하면 입고·출고·재고·보고에 자동 전파
- 입력 시 **차종·거래처·프로젝트를 드롭다운**으로 선택 → 오타 방지
- `총중량 − 공차중량 − 감량 = 입고량/정산중량` **자동 계산**, 재고반영중량 자동 동기화
- ecount로 내보낼 표준 포맷 자동 생성(또는 추후 API 연동)

### 3.2 통합 원장 + 자동 뷰  *(P4·P5 해결)*
- 입고·출고·폐기물·재고이동을 **단일 트랜잭션 테이블**로 통합, 거래처별/현장별 시트는 **자동 필터 뷰**로 대체
- 입출고 컬럼 차이는 시스템 내부에서 표준 스키마로 정규화

### 3.3 자동 집계·보고  *(P2·P6·P8 해결)*
- 갑지(월별·현장별·거래처별 소계)를 **실시간 자동 집계**로 대체 → `#REF!` 원천 제거
- **일일 출고보고 자동 생성**(표/이미지) → 카톡 공유용 파일 원클릭 출력

### 3.4 실시간 재고 + 재고평가  *(P9 해결)*
- 프로젝트×품목 단위 **재고 스냅샷**(Σ입고 − Σ출고), 재고이동 자동 반영
- 품목별 잔량 × 추정단가 = **재고평가 자동**, 실현+미실현 손익 즉시 확인

### 3.5 폐기물·올바로 관리  *(P7 해결)*
- 폐기물 반입/반출에 **올바로 신고 상태(O/X)** 필드와 인계일 관리, 미신고 건 알림

### 3.6 프로젝트(차수) 손익 대시보드
- 매입가·인건비(공수)·운송비·폐기비 vs 매각수입 + 재고평가 → **차수별 예상 최종손익** 자동 산출
- 대표이사 보고서(손익현황) 자동 초안 생성

### 3.7 총무 알림  *(P10 해결)*
- 차량검사 유효기간·자격증·교육 **만료 D-day 알림**(대시보드/알림)
- 차량·중장비·어테치 이동내역, 정비명세서 이력 관리

## 4. 자동화 우선 대상 (기술 포인트)

- **공수체크(matrix) → 일자별 인건비**: `pd.melt` 언피벗 후 비용원장 반영
- **입고/출고 컬럼 정규화**: 유형별 매핑 테이블로 표준 스키마 변환
- **재고 스냅샷**: 특정 시점 기준 원장 누계 쿼리(입고+ / 출고−)
- **스테이징 → PostgreSQL upsert**: 재적재 시 중복 방지(계근일+차량번호+제품 키)
- **갑지 자동 집계**: DB 집계 쿼리로 대체(수동 새로고침 제거)

## 5. 단계별 구축 로드맵 (1인 개발 기준)

**1단계 — Excel 자동화 파이프라인 (최우선)**
- 입고/출고/폐기물 Excel 표준화 + Python 정규화 + PostgreSQL 적재
- 통합 원장 + 자동 갑지 뷰 + 일일보고 자동 생성
- → 담당자의 3중 입력과 수동 집계를 즉시 경감

**2단계 — 재고·손익**
- 재고 스냅샷/재고평가, 차수별 손익 대시보드, 대표이사 보고 초안

**3단계 — 연동**
- ecount export/API, 세무사랑 연동, 올바로 신고 상태 관리

**4단계 — 총무 모듈**
- 차량검사·자격증 만료 알림, 이동/정비 이력, 도시락 관리

## 6. 담당자에게 추가로 확보할 정보

- 입고/출고 Excel의 **월별 원본 파일 1~2세트**(현재 진행 차수 포함)
- ecount **export 포맷/API 사용 가능 여부**
- 폐기물 **올바로 신고 규칙**(어느 시점 O 처리, 기준업체량 산정 방식)
- 손익 **확정 시점 정의**(차수 종료 판단 기준)
- **예외/수기 정정 사례**(단가수정·입금 정정·감량 협의 등)
